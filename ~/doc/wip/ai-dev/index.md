# 2026 AI dev notes

## Documentation bloat

Commit messages are the best docs. Docs grow until they can't be properly
searched. They either have lots of the same thing (they state the obvious)
or they're surprising and unlikely. Unlikely things are hard to write with AI.
They reflect the codebase, they are low entropy.

Tidy the above and you have a whole article.

## The human bottleneck

Bots want you to talk to humans. They want to talk to humans, but they can fuck
right off. Don't let the bots talk to humans, and don't give people tasks. You
have bots for that. Nobody likes tasks. They'll avoid them and you'll end up
blocked. If you want to work with other people you need to keep merging. Fix
your own review comments, don't play ping-pong or you'll end up with nobody to
play with.

## Refactoring

You can make a spring by winding a piece of wire while it's hot. Good fucking
luck when it's cold and it's been under load for months.

## The test burden

Code that reflects the tests is robust code. The code takes too long to run.
The code has a weight that bends everything to its shape. Words have gravity.
